# pce-neon

Personal-Cashflow-Engine: eine lokale PWA, die Einnahmen aus eigenen Projekten erst gegen Fixkosten rechnet und den Überschuss in Schulden lenkt. Gebaut mit Gemini 4 Neon im Swarm-Modus von Antigravity.

| Datei | Zweck |
| --- | --- |
| `docs/ARCHITEKTUR.md` | Verbindliche Spezifikation: Module, Datenmodell, Wasserfall, Umfang je Modul |
| `docs/SWARM_PROMPT.md` | Der Prompt zum Starten des Swarms |
| `docs/ABNAHME.md` | Prüfliste für den Verifier |
| `docs/reference/core/` | Getesteter Kern (Datenmodell, Wasserfall, Datenbank, 11 Tests) |
| `AGENTS.md` | Dateigrenzen und harte Regeln für alle Agenten |

Start: `docs/SWARM_PROMPT.md` öffnen und den Schritten folgen.
